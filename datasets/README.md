# B.Tech Learning Platform — Curriculum Datasets

This folder contains pre-configured, structured JSON datasets for the **B.Tech Learning, Assessment & Programming Practice Platform**.

## Files in this Directory

| File | Purpose | Content Type |
|---|---|---|
| `subjects.json` | Core B.Tech programming languages and branches | Python, C, C++, Java, JavaScript, SQL, DSA |
| `courses.json` | Course catalog | Course metadata, thumbnail, access tier (free/premium), tags |
| `modules_lectures.json` | Hierarchical modules & sequential lectures | Video links, markdown notes, prerequisites, attachments |
| `theory_questions.json` | Theory question bank & MCQs | 4-option MCQs, answer keys, explanations, exam questions |
| `coding_problems.json` | Programming challenges | Problem statements, constraints, sample & hidden test cases, starter code |
| `subscription_plans.json` | Commercial layer & coupons | Free tier, Pro Monthly, Pro Yearly, promotional discount codes |

## How to Add or Edit Content
You can modify content in two ways:
1. **Direct File Editing**: Edit any `.json` file in this folder and click **"Import Datasets"** in the **Admin CMS > Data Manager** tab.
2. **Dynamic Admin CMS**: Log in as an administrator to create, edit, reorder, or delete courses, lectures, MCQs, and coding problems live in your browser with zero rebuilds.
